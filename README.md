# Voice Assistant Project

## Description
This Python project is a voice-controlled assistant that allows users to control their computer using voice commands.

## Features
- Open applications (Chrome, Notepad, Calculator, Paint)
- Open websites (Google, YouTube)
- Voice-based Google search
- Type text using voice
- Control mouse (move, click, scroll)
- Take screenshots
- Control volume
- Window controls (copy, paste, close, minimize)

## Technologies Used
- Python
- SpeechRecognition
- pyttsx3
- pyautogui
- keyboard
- webbrowser
